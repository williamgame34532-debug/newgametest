# STICKMAN: ЛЕГЕНДЫ АРЕНЫ (Unity)

Эпичные битвы стикменов в стиле анимаций с YouTube. Опиши героя словами (и/или нарисуй ему что‑нибудь), арена сама
сгенерирует внешность, характеристики и способности. Персонажи дерутся сами (или ими управляют игроки), льётся кровь,
камера летает, на арену с парашютом падает оружие.

## Как запустить

1. Установи **Unity 2022.3 LTS** (подойдёт и Unity 6 — проект откроется с обновлением).
2. Unity Hub → **Add / Open** → выбери папку `StickmanLegends`.
3. Дождись импорта. Скрипт `Assets/Editor/StickmanSetup.cs` сам создаст сцену `Assets/Scenes/Main.unity`
   и добавит её в Build Settings.
4. Нажми **Play**. Всё (меню, арены, бойцы, кровь, музыка) создаётся кодом — никаких префабов настраивать не нужно.
5. Сборка игры: File → Build Settings → Build.

> Игра стартует из кода (`[RuntimeInitializeOnLoadMethod]` в `Game.cs`), поэтому работает в любой открытой сцене.

## Что есть

- **1 или 2 игрока.** В режиме 1 игрока ты описываешь обе команды и смотришь бой (или управляешь красным лидером).
  В режиме 2 игроков каждый создаёт бойцов за свою сторону и может управлять своим лидером с одной клавиатуры.
- **До 4 бойцов за сторону** (1 + ещё 3).
- **Генерация героя по описанию** (русский и английский): сила/скорость/защита/ловкость, размер, цвет, аксессуары
  (повязка ниндзя, шляпа мага, ковбойская шляпа, рога, корона, нимб, плащ, кибер‑визор, шарф) и до 3 способностей:
  огненный шар, молния, телепорт за спину, рывок, щит, регенерация, двойной прыжок, ледяные осколки, удар по земле,
  невидимость, ярость, вампиризм, лазер из глаз, телекинез.
- **Бессмертие запрещено.** Слова «бессмертный», «неуязвимый» и т.п. заменяются на регенерацию, у каждого бойца
  есть слабость (урон ×2 и отключение регенерации). Характеристики нормализуются — всемогущих не бывает.
- **Рисование**: планшет в редакторе — рисунок появляется на голове бойца (шляпа, маска, причёска).
  Оружие тоже можно нарисовать.
- **Оружие по описанию**: мечи, катаны, топоры, молоты, биты, копья, косы, посохи стихий, пистолеты, автоматы, дробовики,
  луки, сюрикены, гранаты, бензопилы. Стихии: огонь, лёд, молния, яд, тьма. Оружие из арсенала **падает с неба**.
- **Кровь**: брызги, лужи, кровотечение, обезглавливание, фонтаны; тела падают как тряпичные куклы. Количество крови
  настраивается (вплоть до «без крови»).
- **Динамичная камера**: следит за всеми бойцами, зум, тряска, стоп‑кадр на ударах, замедление на добивании.
- **Стили арены**: лист бумаги, тёмная арена, поле, город, киберпанк (неон, дождь). Главное меню меняется под стиль.
- **Музыка**: встроенный эпичный саундтрек синтезируется прямо в игре; в настройках можно выключить музыку или вставить
  прямую ссылку на `.mp3 / .ogg / .wav` (или путь к файлу на диске). YouTube‑ссылки напрямую не работают.
- **Пауза (Esc)**: продолжить, остановить бой и вернуть всех на исходные позиции (кровь можно оставить),
  начать заново, настройки, смена команд, выход в меню.
- Всё сохраняется автоматически (PlayerPrefs). Сброс: меню Unity → *Stickman Legends → Сбросить сохранения*.

## Новое в версии 11

- **До 99 своих умений** (каждое с новой строки во вкладке «Способности»): R, T, Y — первые три, H — по очереди
  все остальные. ИИ и умение отчаяния тоже перебирают весь список.
- **Стадии**: «имеет злую стадию, в которой появляется плащ и чёрные глаза и бьёт в 3 раза быстрее» — отдельное
  умение-превращение на 15 сек: плащ, багровые глаза, тёмная аура, удары в 3 раза быстрее. Вне стадии этих
  свойств нет. Так же «режим берсерка, в котором растут рога и он в 2 раза сильнее».
- **Клинки из тела**: «достаёт из себя клинки, которые наносят очень много урона» — веер из 7 клинков (в нокдауне 9)
  + оружие «Клинок из тела» с огромным уроном.
- **Лазеры из глаз**: луч идёт из головы; «испепеляет полностью» — ослабленный враг сгорает дотла.
- **Сфера-взрыв**: «превращается в сферу и взрывается, нанося урон всем по окружности» — боец сворачивается
  в пульсирующую сферу, которая взрывается кольцом.
- «Бьёт в N раз быстрее» — это теперь скорость ударов, а не бега. Названия умений — как их написал игрок.

## Новое в версии 8

- **Описания понимаются точнее**: «череп вместо головы» (голова-череп со светящимися глазницами),
  «черепная броня» (броня с черепами), **поножи**, **наручи**; любые «X вместо головы» — тыква, огонь,
  экран, кристалл или предмет.
- **Собственное умение из описания**: форма (вокруг себя / с неба / луч / волна по земле / на себя) + стихия
  (в т.ч. тёмная) + эффект (окаменение, заморозка, поджог, отбрасывание, притягивание, подъём, оглушение,
  высасывание жизни, взрыв) + «убивает». Пример: «вокруг себя создаёт тёмные молнии, которые превращают врагов
  в статуи, которые их убивают» — кольцо тёмных молний, враги каменеют и рассыпаются.
- **Умение отчаяния**: в нокдауне, лёжа или под колоссальными ударами боец вырывается — **подпрыгивает**,
  вокруг него **взрыв**, который откидывает всех врагов (они падают, оглушены и встают не сразу), а на пике прыжка
  срабатывает его умение. Затем ~3 сек **окно контратаки**: удары быстрее и на 35% сильнее, можно добивать лежащих.
- **Оружие с описанием через запятую**: «Тёмный меч, пронзает всех ровно через голову, отрезая их части» —
  удары всегда в голову, задевает всех на пути, тёмная сила, **отрубает руки и ноги** (части тела летят и остаются
  на земле). Эффекты умений работают и у оружия («посох, превращает врагов в камень»).
- **Больше 3D**: новый «Постоянный 3D-вид» — перспективная камера чуть сверху и сбоку, фон уходит в глубину,
  под ногами пол; 3D-облёты чаще.
- Исправлено: у бегущей толпы на фоне головы и руки отрывались от тел.
- В виде Dojo снаряжение подогнано под толстые силуэты.

## Новое в версии 7

- **Режим «Один против всех»** (главное меню → третья кнопка). Описываешь одного героя (первый красный боец) —
  на него со всех сторон бегут волны стикменов: сначала безоружная пехота, потом мечники, стрелки, ниндзя,
  колдуны, бронированные громилы, а каждая 5-я волна — **босс**. Враги вбегают с краёв и падают с неба,
  на фоне видна толпа, бегущая к полю боя (чем дальше волна — тем больше толпа). Между волнами — **передышка**:
  здоровье восполняется, с неба падает оружие. Темп и рисовка меняются от волны к волне, рекорд сохраняется.
  Своя музыка по ссылке работает и здесь.
- **Всё, что описано, — на стикмане.** Новые предметы: кепка/шапка, очки, шрам, амулет/ожерелье, рюкзак/колчан,
  щит в руке, бинты, цепи/кандалы. А любой незнакомый предмет, который герой «носит», «держит», «имеет»,
  «на голове/шее/спине/поясе» (серьга, фонарь, деревянная нога…), получает свою форму и место на теле —
  и появляется в списке «Понял».
- **Мрачнее и мощнее**: новая настройка «Мрачная атмосфера» — тяжёлая багрово-чёрная виньетка, затемнение кадра,
  оседающий пепел, пульсирующий красный край экрана при низком здоровье. Две новые мрачные арены —
  **«Кровавая луна»** (огромная луна, мёртвые деревья, кресты, багровый туман) и **«Пепелище»**
  (горящий город, дым до неба, тлеющие угли, искры и пепел). Новые стили рисовки в бою:
  **«Кровавый нуар»** (чёрные силуэты на светлом фоне, ярко-алая кровь, кровавая луна) и **«Багровая ночь»**.
- **Новая кровь**: густой тёмно-багровый цвет с влажными алыми бликами; быстрые капли вытягиваются в штрихи
  по направлению полёта; клинки оставляют **кровавые дуги**; тяжёлые удары поднимают тёмную кровавую взвесь;
  лужи растекаются с брызгами вокруг и **засыхают**, темнея со временем; по стенам кровь **стекает потёками**;
  на телах остаются **раны**, которые сочатся; мощные удары и убийства забрызгивают **экран** (отключается в настройках).
- Dojo-вид бойцов (толстые силуэты, круглые головы, светящиеся глаза), ауры разных стихий, руны, ножны,
  улучшенное оружие, арены «Долина» и «Закат», стили «Тени Hyun», «Акварель», «Неон», «Старое кино»,
  3D-облёт камеры в эпичные моменты, новые звуки, захват и бросок (Q / J), парирование с контратакой,
  рывок двойным нажатием, выбор вида бойцов в настройках.

## Новое в версии 5

## Новое в версии 4

- **Фильм битвы**: каждая дуэль записывается. После победы — кнопка «ФИЛЬМ БИТВЫ»: повтор смонтирован как
  стикмен‑анимация (спокойные моменты ускоряются, удары и нокауты замедляются с наездом камеры, рисовка меняется:
  арена → плоская дуэль → чернила → негатив, на нокаутах — красный «кадр удара»).
- **«Сохранить кадры»**: повтор записывается в PNG (30 кадров/с) в папку `Duels` внутри `Application.persistentDataPath`.
  Видео: `ffmpeg -framerate 30 -i frame_%05d.png duel.mp4`.
- **В живом бою**: темп растёт со временем, рисовка меняется по ходу дуэли, на нокаутах — кадр удара
  (оба переключателя в настройках).
- **Генерация из любых слов**: «убить можно только солью» → новая слабость и арена сбрасывает оружие из соли;
  «сражается гитарой», «кидает кирпичи» → новое оружие; «умеет петь так, что…» → новое умение со своим названием и цветом.
- **Оружие‑призыватель**: «посох, который призывает скелетов», «меч, вызывающий клонов» — оружие даёт призыв.
  Виды призванных: скелеты, клоны, демоны, зомби, духи, воины, дроны, тени.
- **Аура и одежда**: «синяя аура», «чёрный фрак», «красный галстук», «оранжевое кимоно», «джинсы», «толстовка»,
  «пальто», «юбка» — всё рисуется на бойце в нужном цвете.
- **Стикмены ближе к референсам**: крупные круглые кулаки и стопы, толстые линии, стиль «Дуэль» как в анимациях.

  встаёт в несколько фаз (сел → на колено → стойка, или отжался → на колено), акробаты — подъёмом разгибом.
- **Стили по референсам**: «Туманный лес» (чёрные силуэты со светящимися глазами) и «Сияние»
  (фиолетовый градиент со световой вспышкой).

## Новое в версии 2

- **Умный разбор описаний**: слова с любыми окончаниями, отрицания («не умеет летать», «не боится огня» → иммунитет),
  числа («здоровье 500», «сила 9/10», «в 2 раза быстрее», «урон x2», «рост 2.5 метра»), стиль боя (боксёр, каратист,
  акробат, громила). В редакторе видно, что именно арена поняла.
- **Условия смерти**: «убить можно только ударом в голову», «победить только проткнув молнией», «боится льда или яда»,
  «слабое место — спина», «умирает только от взрыва». Если герой умирает только от особого удара — обычные удары
  не могут его добить, а арена сбрасывает подходящее «оружие‑убийцу»; через 100 секунд — внезапная смерть.
- **Боёвка как в стикмен‑анимациях**: комбо‑цепочки (джеб → кросс → хук → апперкот), хай‑кики, вертушки, подсечки,
  удары в прыжке и в пике, подброс и жонглирование в воздухе, отскок от земли и стен, нокдаун и подъём, перекаты
  и сальто с неуязвимостью, удары в спину, столкновение ударов (CLASH), пробитие блока.
- **Графика**: контур персонажей, тени, следы‑«смазы» от ударов и оружия, искры удара с лучами, вспышки,
  трещины в земле и стенах, линии скорости, кинематографичные полосы при замедлении, виньетка.
- **HUD**: полосы здоровья в стиле файтингов со «следом» урона, портреты, таймер, счётчик комбо, перезарядка
  умений, условие смерти каждого бойца.

## Управление (если включено управление лидером)

| | Игрок 1 (красные) | Игрок 2 (синие) |
|---|---|---|
| Бег | A / D | ← / → |
| Прыжок | W | ↑ |
| Блок | S | ↓ |
| Перекат | S + A/D | ↓ + ←/→ |
| Апперкот (подброс) | W + F | — |
| Подсечка | S + G | — |
| Удар / оружие | F | K (или Num1) |
| Пинок | G | L (или Num2) |
| Метнуть второе оружие | E | U (или Num3) |
| Захват и бросок | Q | J |
| Рывок | A/D дважды | ←/→ дважды |
| Парирование | S в момент удара | ↓ в момент удара |
| Способности | R, T, Y, H | I, O, P, ; |
| Пауза | Esc | Esc |

Оружие подбирается, если пробежать по нему.

## Примеры описаний

- «Очень быстрый ниндзя в повязке, телепортируется за спину и делает рывок. Слабость: огонь.» + оружие «Острая катана»
- «Огромный рогатый демон, очень сильный, бьёт по земле и кидает огненные шары, боится льда» + «Огромный огненный топор»
- «Зелёный робот с лазером из глаз. Бессмертный.» → арена запретит бессмертие и выдаст регенерацию + слабость
- «Пират в красной бандане, носит золотую серьгу и деревянную ногу, держит фонарь, со шрамом на лице и в чёрных очках»
- Оружие: «ледяной лук», «ядовитые сюрикены», «посох молний», «дробовик», «гранаты»

## Структура кода (`Assets/Scripts`)

| Файл | Что делает |
|---|---|
| `Game.cs` | точка входа, состояния, сохранения, готовые герои и оружие |
| `GameUI.cs` | весь интерфейс (IMGUI): меню, редакторы, рисование, настройки, HUD, пауза |
| `Parser.cs` | разбор описаний → характеристики, способности, слабость, внешность, оружие |
| `Fighter.cs` | боец: анимация, ИИ, удары, способности, урон, кровь, смерть |
| `Body.cs` | позы и скелет, тряпичная кукла (Верле), отрисовка оружия |
| `Battle.cs` | ход боя, сброс оружия, эффекты, замедление; `CameraDirector` — камера |
| `Projectile.cs` | пули, стрелы, сюрикены, огненные шары, гранаты; `Pickup` — оружие на земле |
| `Particles.cs` | кровь (штрихи, дуги, взвесь, засыхающие лужи, потёки), искры, дым, брызги на экран |
| `Forms.cs` | превращения: формы и их сила |
| `BgDuels.cs` | драки стикменов на заднем плане |
| `WebText.cs` | текст со страницы сайта для описания |
| `Powers.cs` | визуал умений: молнии, удары с неба, лучи, статуи, отрубленные части |
| `Survival.cs` | режим «Один против всех»: волны, боссы, передышки, толпа на фоне |
| `Cine3D.cs` | 3D-переходы камеры |
| `Replay.cs` | запись, фильм битвы, смена рисовки |
| `VideoExport.cs` | сохранение видео (AVI) |
| `Theme.cs` | стили арены и палитры интерфейса |
| `Audio.cs` | синтез музыки и звуков, загрузка своей музыки по ссылке |
| `Draw.cs` | процедурные спрайты, линии, полигоны, GL‑рисование |
