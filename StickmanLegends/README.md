# STICKMAN: ЛЕГЕНДЫ АРЕНЫ (Unity)

Эпичные битвы стикменов в стиле анимаций с YouTube. Опиши героя словами (и/или нарисуй ему что‑нибудь), арена сама
сгенерирует внешность, характеристики и способности. Персонажи дерутся сами (или ими управляют игроки), льётся кровь,
камера летает, на арену с парашютом падает оружие.

## Как запустить

1. Установи **Unity 2022.3 LTS** (подойдёт и Unity 6 — проект откроется с обновлением).
2. Unity Hub → **Add / Open** → выбери папку `StickmanLegends`.
3. Дождись импорта. Скрипт `Assets/Editor/StickmanSetup.cs` сам создаст сцену `Assets/Scenes/Main.unity`
   и добавит её в Build Settings.
4. Нажми **Play**. Всё (меню, арены, бойцы, кровь, музыка) создаётся кодом — никаких префабов настраивать не нужно.
5. Сборка игры: File → Build Settings → Build.

> Игра стартует из кода (`[RuntimeInitializeOnLoadMethod]` в `Game.cs`), поэтому работает в любой открытой сцене.

## Что есть

- **1 или 2 игрока.** В режиме 1 игрока ты описываешь обе команды и смотришь бой (или управляешь красным лидером).
  В режиме 2 игроков каждый создаёт бойцов за свою сторону и может управлять своим лидером с одной клавиатуры.
- **До 4 бойцов за сторону** (1 + ещё 3).
- **Генерация героя по описанию** (русский и английский): сила/скорость/защита/ловкость, размер, цвет, аксессуары
  (повязка ниндзя, шляпа мага, ковбойская шляпа, рога, корона, нимб, плащ, кибер‑визор, шарф) и до 3 способностей:
  огненный шар, молния, телепорт за спину, рывок, щит, регенерация, двойной прыжок, ледяные осколки, удар по земле,
  невидимость, ярость, вампиризм, лазер из глаз, телекинез.
- **Бессмертие запрещено.** Слова «бессмертный», «неуязвимый» и т.п. заменяются на регенерацию, у каждого бойца
  есть слабость (урон ×2 и отключение регенерации). Характеристики нормализуются — всемогущих не бывает.
- **Рисование**: планшет в редакторе — рисунок появляется на голове бойца (шляпа, маска, причёска).
  Оружие тоже можно нарисовать.
- **Оружие по описанию**: мечи, катаны, топоры, молоты, биты, копья, косы, посохи стихий, пистолеты, автоматы, дробовики,
  луки, сюрикены, гранаты, бензопилы. Стихии: огонь, лёд, молния, яд, тьма. Оружие из арсенала **падает с неба**.
- **Кровь**: брызги, лужи, кровотечение, обезглавливание, фонтаны; тела падают как тряпичные куклы. Количество крови
  настраивается (вплоть до «без крови»).
- **Динамичная камера**: следит за всеми бойцами, зум, тряска, стоп‑кадр на ударах, замедление на добивании.
- **Стили арены**: лист бумаги, тёмная арена, поле, город, киберпанк (неон, дождь). Главное меню меняется под стиль.
- **Музыка**: встроенный эпичный саундтрек синтезируется прямо в игре; в настройках можно выключить музыку или вставить
  прямую ссылку на `.mp3 / .ogg / .wav` (или путь к файлу на диске). YouTube‑ссылки напрямую не работают.
- **Пауза (Esc)**: продолжить, остановить бой и вернуть всех на исходные позиции (кровь можно оставить),
  начать заново, настройки, смена команд, выход в меню.
- Всё сохраняется автоматически (PlayerPrefs). Сброс: меню Unity → *Stickman Legends → Сбросить сохранения*.

## Управление (если включено управление лидером)

| | Игрок 1 (красные) | Игрок 2 (синие) |
|---|---|---|
| Бег | A / D | ← / → |
| Прыжок | W | ↑ |
| Блок | S | ↓ |
| Удар / оружие | F | K (или Num1) |
| Пинок | G | L (или Num2) |
| Способности | R, T, Y | I, O, P |
| Пауза | Esc | Esc |

Оружие подбирается, если пробежать по нему.

## Примеры описаний

- «Очень быстрый ниндзя в повязке, телепортируется за спину и делает рывок. Слабость: огонь.» + оружие «Острая катана»
- «Огромный рогатый демон, очень сильный, бьёт по земле и кидает огненные шары, боится льда» + «Огромный огненный топор»
- «Зелёный робот с лазером из глаз. Бессмертный.» → арена запретит бессмертие и выдаст регенерацию + слабость
- Оружие: «ледяной лук», «ядовитые сюрикены», «посох молний», «дробовик», «гранаты»

## Структура кода (`Assets/Scripts`)

| Файл | Что делает |
|---|---|
| `Game.cs` | точка входа, состояния, сохранения, готовые герои и оружие |
| `GameUI.cs` | весь интерфейс (IMGUI): меню, редакторы, рисование, настройки, HUD, пауза |
| `Parser.cs` | разбор описаний → характеристики, способности, слабость, внешность, оружие |
| `Fighter.cs` | боец: анимация, ИИ, удары, способности, урон, кровь, смерть |
| `Body.cs` | позы и скелет, тряпичная кукла (Верле), отрисовка оружия |
| `Battle.cs` | ход боя, сброс оружия, эффекты, замедление; `CameraDirector` — камера |
| `Projectile.cs` | пули, стрелы, сюрикены, огненные шары, гранаты; `Pickup` — оружие на земле |
| `Particles.cs` | кровь, искры, дым, дождь и пятна крови (один динамический меш) |
| `Theme.cs` | стили арены и палитры интерфейса |
| `Audio.cs` | синтез музыки и звуков, загрузка своей музыки по ссылке |
| `Draw.cs` | процедурные спрайты, линии, полигоны, GL‑рисование |
