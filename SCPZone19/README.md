# SCP: Зона-19 — мод для Minecraft 1.20.1 (Forge)

Сюжетная кампания за охрану Зоны-19 в духе *SCP – Containment Breach*: шесть глав, готовый комплекс
содержания, SCP-173 / 096 / 106 / 049-2, оружие, ключ-карты, моргание, новое главное меню и ресурс-пак.
Играется и в одиночку, и в кооперативе на сервере.

## Что внутри архива
| Папка / файл | Что это |
|---|---|
| `mod/` | Исходный проект мода (Forge 47.x, Gradle). Собирается в `scpzone19-1.20.1-1.0.0.jar` |
| `SCP-Zone19-Interface-ResourcePack.zip` | Ресурс-пак «Зона-19: Интерфейс» — кнопки, фоны меню миров и настроек, логотип, панорама, музыка меню, переименованные пункты меню |
| `skins/` | 7 скинов персонала отдельными PNG (подходят и как обычные скины Minecraft) |
| `tools/` | Генераторы всех текстур, моделей, панорамы и звуков (Python + ffmpeg) |
| `README.md`, `CREDITS.md` | Это описание и авторы/лицензии |

## Установка
1. Поставь **Minecraft Forge 1.20.1** (47.x).
2. Собери мод (или скачай готовый `.jar` из GitHub Actions, см. ниже) и положи `.jar` в `mods/`.
3. Ресурс-пак положи в `resourcepacks/` и включи в «Настройки → Пакеты ресурсов» поверх стандартного.
4. Для сервера — тот же `.jar` в `mods/` сервера; у каждого игрока тоже должен быть мод.

### Сборка из исходников
```
cd mod
./gradlew build          # Windows: gradlew.bat build
```
Готовый файл: `mod/build/libs/scpzone19-1.20.1-1.0.0.jar`. Нужна Java 17.
В репозитории также есть workflow `.github/workflows/build-scpzone19.yml`: при каждом пуше GitHub сам
собирает `.jar` + ресурс-пак и выкладывает их артефактом `scpzone19-1.20.1`.

## Как играть
- **Главное меню** заменено терминалом СБ Зоны-19: панорама коридора, мигающий свет, панель обновлений
  справа, окно «Что нового» при первом запуске. Кнопка «Старое меню» вернёт ванильное до перезапуска.
- **Одиночная кампания** → создай любой мир. При первом входе игрока перенесёт в измерение
  `scpzone19:zone19`, где автоматически строится комплекс (первая постройка занимает пару секунд).
- **Терминал** открывается сам при первом входе и по клавише **J**: брифинг главы, список глав,
  выбор формы, архив документов SCP.
- **Моргание** (как в SCP:CB): шкала внизу слева, **B** — моргнуть самому. Пока ты моргаешь,
  SCP-173 и SCP-096 считают, что ты не смотришь. Противогаз и глазные капли замедляют шкалу.
- **Двери** открываются ключ-картой нужного уровня (карта может лежать где угодно в инвентаре).
  Оператор в креативе: Shift + ПКМ пустой рукой по двери меняет требуемый уровень.
- **Оружие**: ПКМ — стрелять (MP5SD и P90 — зажать), Shift + ПКМ — перезарядка, пустой магазин
  перезаряжается сам. Полоска под иконкой — патроны в магазине.
- **Рация** (ПКМ) повторяет текущий приказ, **S-NAV** показывает расстояние и направление к цели.
- Внутри комплекса игроки в выживании переводятся в режим приключения, а при смерти сохраняют
  инвентарь и возрождаются на чекпоинте главы.

### Главы
1. **Пересменка** — арсенал, снаряжение, пост на КПП.
2. **Код красный** — прорыв содержания, перезапуск дверей в посту управления.
3. **Мёртвые не спят** — зачистка Тяжёлой зоны от SCP-049-2, медпункт и доктор Вэнс.
4. **Не моргай** — три терминала повторного содержания под присмотром SCP-173.
5. **Старик** — генераторы, SCP-106 сквозь стены, протокол «Ломатель бедренной кости».
6. **Ворота B** — сейф O5, коридор с SCP-096, эвакуация с МОГ Эпсилон-11.

### Мультиплеер
Прогресс сюжета общий на весь мир — смену проходят вместе. Форма, выбранная в «Персонал и формы»,
видна всем. Команды:
- `/zone19 enter` · `/zone19 leave` · `/zone19 status` — всем;
- `/zone19 chapter <1-6>` · `/zone19 skip` · `/zone19 reset` — операторам.

### Настройки
`config/scpzone19-common.toml` — автовход в зону, режим приключения, сохранение инвентаря, моргание.
`config/scpzone19-client.toml` — своё главное меню, окно обновлений, выбранная форма, эмбиент.

## Пересборка ассетов
Все PNG/OGG/JSON-модели генерируются скриптами из исходников SCP:CB:
```
git clone https://github.com/Regalis11/scpcb
tools/build_assets.sh /путь/к/scpcb
```
Нужны Python 3 с Pillow и numpy, ffmpeg с libvorbis.
