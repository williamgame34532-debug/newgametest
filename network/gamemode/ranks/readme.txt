ПАПКА РАНГОВ (КЛАССОВ)

Каждый sh_*.lua файл здесь включается автоматически при загрузке
геймода. Один файл = один класс (можно и несколько Register в файле).
Скопируйте sh_wallhammer.lua или sh_refugee.lua как шаблон — в шапке
sh_wallhammer.lua расписаны все поля.

Класс без поля model не трогает внешность персонажа (пример: refugee).
Назначение: /setclass <игрок> <id>. Снятие: /setclass <игрок> clear.
Название класса: name = "ключ" добавьте в gamemode/lang/sh_ru.lua
(и sh_en.lua), либо пишите строку напрямую.
