# Критик модов (Mod Critic)

Мод для Minecraft **1.21.1 / Forge 52.1.20**, который помогает честно решить, какой мод в сборке
самый интересный. Каждый мод оценивается по восьми критериям, оценки складываются во взвешенный
итог, строится рейтинг, раздаются награды («Самый атмосферный» и т. п.), а два мода можно
сравнить бок о бок. На сервере с этим модом оценки всех игроков собираются вместе.

## Как открыть

| Способ | Что делает |
|---|---|
| Кнопка **★ Критик модов** в левом верхнем углу главного меню | открывает экран оценок |
| Та же кнопка в меню паузы (Esc) | открывает экран оценок прямо в игре |
| Клавиша **N** (меняется в «Управление → Критик модов») | открывает экран оценок |
| `/critic` | то же самое, команда сервера (нужен мод и на сервере, и у игрока) |

## Экран оценок

* Слева — список всех установленных модов (берётся из Forge `ModList`, без `minecraft`, `forge` и самого
  «Критика»). Четыре мода сборки — **Эхо Сна, Прятки и Охота, Память блоков, Симбионт** — закреплены сверху
  под заголовком «Сборка» и отмечены золотой звездой. Есть поиск, прокрутка колёсиком,
  стрелки ↑/↓ переключают мод. Справа от названия — текущая взвешенная оценка.
* Справа — оценка выбранного мода по критериям (каждый от 1 до 10, ползунок + золотые звёзды,
  10 баллов = 5 звёзд, половинки звёзд поддерживаются):
  **Идея, Атмосфера, Геймплей, Визуал, Звук, Баланс, Оригинальность, Реиграбельность**.
  Наведи на название критерия — появится подсказка, что именно оценивать.
  Ползунок двигается мышью или стрелками ←/→.
* Поле комментария (до 256 символов).
* Кнопки: **Сохранить** (пишет файл и отправляет на сервер), **Сбросить** (удаляет оценку мода),
  **Веса**, **Итоги**, **Готово** (тоже сохраняет).

Мод, который ещё не оценивался, показан серым; оценка появляется, как только сдвинешь любой ползунок.

## Веса критериев

Каждому критерию можно задать вес от 0 до 5 (шаг 0,5). Итог = взвешенное среднее.
Справа видно, какую долю итога даёт каждый критерий, внизу — живой «Топ-3» с текущими весами.
Есть готовые наборы: «Поровну», «Важнее геймплей», «Важнее атмосфера».

## Итоги

Три вкладки и переключатель **Источник** (мои оценки → среднее по серверу → каждый игрок отдельно):

1. **Рейтинг** — места с медалями, полоса итоговой оценки, звёзды, значки наград.
   Наведи на строку — подробности по критериям и комментарии; нажми — мод откроется в сравнении.
2. **Критерии** — 8 карточек наград (лучший мод по каждому критерию); нажми на карточку,
   и ниже появится горизонтальная диаграмма всех модов по этому критерию.
3. **Сравнение** — два мода друг напротив друга (стрелки ◀ ▶ выбирают моды), зеркальные полосы
   по каждому критерию, итог и вердикт «кто лучше и по скольким критериям».

Кнопки внизу:
* **Экспорт .md** — сохраняет отчёт `modcritic-results.md` в папку игры (и копию в `config/modcritic/`);
* **Копировать** — тот же отчёт (Markdown с таблицами) в буфер обмена — удобно вставить в Discord;
* **Отправить всё** — отправить на сервер все свои оценки разом;
* **⟳** — заново загрузить оценки с сервера.

## Где хранятся оценки

`config/modcritic/ratings.json` — обычный JSON (UTF-8): веса и оценки по каждому моду
(`scores` — 8 чисел в порядке критериев выше, `comment`, `time`). Файл можно переносить между
компьютерами. Если файл повреждён, он сохраняется как `ratings.json.broken`, и мод начинает с чистого листа.

## Мультиплеер

* Мод **не обязателен** ни на сервере, ни у игроков. Канал сети необязательный:
  с модом можно зайти на ванильный сервер или сервер без мода — тогда всё работает локально,
  а пакеты на сервер не отправляются.
* Если мод стоит и на сервере, то при сохранении оценки отправляются на сервер и хранятся в мире
  (`world/data/modcritic_ratings.dat`). У каждого игрока — свои оценки, повторная отправка их заменяет.
* В «Итогах» появляется источник «Среднее по серверу» и рейтинги каждого игрока.
  Средняя считается по всем игрокам, оценившим мод; итог считается с **твоими** весами.

### Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/critic` | все | открыть экран оценок (если мод есть у игрока) |
| `/critic open results` | все | открыть «Итоги» сразу со средним по серверу |
| `/critic results` | все | рейтинг сервера в чате (топ-10, награды; наведи на мод — подробности) |
| `/critic results <игрок>` | все | рейтинг конкретного игрока |
| `/critic players` | все | кто и сколько модов оценил (имена кликабельны) |
| `/critic clear [игрок]` | операторы (уровень 2) | удалить все оценки на сервере / оценки игрока |

Команды в чате работают даже у игроков без мода (текст показывается по-английски).

## Сборка

Собирается GitHub Actions (`.github/workflows/build-mods.yml`), готовый jar — в `mods/dist/`.
Логотип для списка модов рисует скрипт `tools/make_logo.py` (Pillow).
