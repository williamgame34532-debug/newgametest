# HLA 5.25

1. Интро: 3D-сцена рисуется в полноэкранной VGUI-панели (как DModelPanel) — модель транспортника рисуется надёжно; камера неподвижна, транспортник висит в профиль, небо карты плывёт.
2. Радиальное меню — держать G (`cl_radial.lua`, `sh_radial.lua`): РУКИ (обычно, скрестить, за спиной, вверх, у рации) и пять групп фраз-войслайнов (говорятся как обычная речь: голос, текст над головой, строка чата). ЛКМ — выбрать/открыть, ПКМ — назад, отпустить G — выполнить пункт под курсором.
   Позы — поворот костей рук (ValveBiped). Если на модели выглядит не так: `hla_pose_set <cross|back|up|radio> <ValveBiped.Bip01_...> <p> <y> <r>` (админ), сохраняется в `data/hla/poses.json`. Позы сбрасываются, когда берёте оружие.
3. Инвентарь: стопки (патроны ×5, таблетки ×5, батареи ×3, аптечки ×2), счётчик на ячейке; перекладывание одинаковых — объединяет стопки; старые сохранения читаются.
4. Контейнеры с лутом (`entities/entities/hla_container`, `sh_loot.lua`, `cl_container.lua`):
   - спавн: меню спавна → Энтити → Half-Life: Alyx → «Контейнер с лутом» (админ);
   - E — окно обмена: слева контейнер, справа инвентарь, ЛКМ по предмету — переложить, «ВЗЯТЬ ВСЁ»;
   - C-меню → ПКМ по контейнеру → «Настроить контейнер»: название, модель (8 вариантов HL2), ячейки 1–16, таблица лута, пополнение раз в N минут, «НАПОЛНИТЬ СЕЙЧАС»;
   - таблицы лута (C-меню → «Таблицы лута» или из настройки контейнера): предмет, шанс %, количество от–до; `data/hla/loot.json`;
   - контейнеры сохраняются по карте: `data/hla/containers/<карта>.json`.
5. Замок Альянса — снова порт `ix_combinelock` как есть (установка на дверь и позиция свечения из оригинала), заменено только свечение на наше; без зависимостей Helix; звуки — присланные пользователем.
