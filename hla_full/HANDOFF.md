# HANDOFF — режим Half-Life: Alyx для Garry's Mod (hlalyx), версия 5.24.5

## 1. Цель пользователя и ограничения
- Ролевой режим «Combine RP» в стиле Half-Life: Alyx для GMod: игроки — юниты Альянса (ЭХО-NNN), визор-HUD, отряды, сюжет по главам, редактор, фабрикатор смолы, терминалы, силовые поля, замки Альянса.
- Пользователь пишет по-русски; отчёты — на русском.
- Работать строго по `SKILL.md` пользователя (strict-project-workflow): делать только описанное (сверх — только при «додумай сам»), проверять сразу, одно независимое ревью субагентом перед выдачей, без поясняющих комментариев в коде (описание — в Markdown), в архив — только изменённые файлы (кроме прямой просьбы о полном архиве).
- Отдельное сообщение `1` — передача работы (этот документ).
- Контент Valve/HL:A (модели, текстуры, звуки) в git не хранится (`.gitignore`), передаётся архивами.

## 2. Исходный проект и зависимости
- Репозиторий: `williamgame34532-debug/newgametest`, ветка `claude/elegant-davinci-grbnie`, папка `hla_full/`.
- Режим: `garrysmod/gamemodes/hlalyx` (база — sandbox).
- Аддоны контента: `garrysmod/addons/hla_*_content`, `hla_shaders`.
- Нужно у игрока/сервера: Garry's Mod + Half-Life 2 (входит), модели юнитов (`models/cultist/hl_a/...`, `models/nemez/...`), оружие TFA (`tfa_osips`, `tfa_ocipr`, …), для камер/NPC — по желанию VJ Base с HL:A-зомби.

## 3. Что сделано (главное по системам, файлы в `gamemode/`)
- HUD визора: `cl_hud.lua`, `cl_hudcurve.lua`, `cl_squads.lua` (строки `<:: ::>`, карточка зоны), `sh_markers.lua` (метки, метки целей главы, лента биосигналов).
- Ник над игроком (эмблема пользователя + шрифт Tektur): `cl_world.lua`; вспышка камер там же.
- Чат и рация: `sh_chat.lua`, `cl_chat.lua`, `sv_chat.lua`; войс-панель `cl_voice.lua`.
- Сюжет/раунды/голосование/ПвП/триггеры глав/цели глав/диспетчер: `sh_story.lua`, `sv_story.lua`, `cl_story.lua`; `hla_story_status` — диагностика.
- Редактор (`hla_editor`, админы): `cl_editor.lua` — главы, ПвП, NPC, зоны, десантник, фабрикатор (кнопка), диспетчер, рация, общее + удаление.
- Камеры Альянса (уникальные КАМ-NNN, своё «зрение», тревога диспетчера): `sv_cameras.lua`.
- Боты как юниты, вступают в отряд игрока: `sv_bots.lua`.
- Фабрикатор: `fabricator/*`, `entities/entities/hla_fabricator`; настройка предметов и свои предметы: `sh_fabcfg.lua` (`data/hla/fabricator.json`), окно C-меню `cl_fabeditor.lua`; страницы в меню (`C.TabCat`: tab = категория + страница*16).
- Инвентарь (в т.ч. патроны-предметы): `sh_items.lua`, `sv_inventory.lua`, `cl_tabmenu.lua` (Q — меню; у админов Q — Sandbox, Shift+Q — меню).
- Скорборд (TAB): `cl_scoreboard.lua`. Пауза (Esc): `cl_pause.lua`.
- Анимации, повороты, предохранитель Shift+E+R + связь с TFA «Safe»: `sh_anims.lua`.
- Интро (небо карты, транспортник на месте, Пробел — меню): `cl_intro.lua` (`hla_intro 0` / `hla_intro_play`).
- Десантник по точкам: `sv_dropship.lua`, `cl_dropship.lua`.
- Эффекты/шейдер атмосферы: `cl_effects.lua` + аддон `hla_shaders` (`shaders/fxc/hla_atmos_ps30.vcs`, исходник `shadersrc/hla_atmos_ps30.hlsl`).
- Энтити: `hla_terminal`, `hla_terminal_cams`, `hla_forcefield` (+ `weapons/hla_ff_tool`), `hla_combinelock` (замок; `data/hla/locks/<карта>.json`; подстройка свечения `hla_lock_lamp_x/y/z`), `hla_npc*`, `hla_health_station`.
- Подробные описания: `docs/CHANGES_5_22.md`, `CHANGES_*.txt`.

## 4. Удаления, переименования, порядок применения
- Архив полный: распаковать в папку `GarrysMod/garrysmod` (с заменой). Перед этим удалить старую `gamemodes/hlalyx`.
- Удалённых файлов относительно прежних сборок нет; ID-счётчики и сохранения в `data/hla/*` совместимы (старый формат `fabricator.json` читается).

## 5. Референсы, ресурсы, условия
- Скриншоты пользователя (HUD/ник гражданина Minerva HL2RP — только как образец вида).
- Эмблема: картинка пользователя (знак Альянса), до этого — реконструкция `riggs9162/combine-logo-studio` (без лицензии; эмблема — собственность Valve).
- Шрифты: Exo 2, Tektur, Roboto Condensed, Russo One, Play, IBM Plex Mono — OFL/Apache (лицензии рядом в `resource/fonts`).
- Звуки замка — присланы пользователем (переведены в WAV). Радиоголос — HL2 (sound/hla/radiovoice).
- TFA Base — у пользователя (предохранитель через `IsSafety`/`CycleSafety`).
- Контент HL:A (модели станций, текстуры) — сконвертирован из файлов пользователя (`tools/hla_convert`).

## 6. Команды сборки и проверки
- Тесты: `python3 tools/check.py` (23 проверки, Lua через lupa/ctypes).
- Синтаксис/загрузка клиента: заглушка `/tmp/mock/load.lua` (во временной папке, не в репо) — через lupa.
- Шейдер: `shadersrc/build_shaders.bat` (или wine `hlslc.exe` + `pack_vcs.py`).
- Сборка GMA без gmpublisher: `python3 tools/gma/make_gma.py <папка аддона> <out.gma>` (белый список = официальный gmad).
- Удаление комментариев из Lua: скрипт-токенизатор (был во временной папке; логика: строки/длинные строки сохраняются, `--` и `--[[ ]]` вырезаются).

## 7. Проверки и ревью
- После каждой правки: синтаксис всех Lua (lupa), 23 теста, загрузка клиента на заглушке.
- Ревью субагентом проведено для 5.22, 5.23, 5.24 (боты/редактор/замок); подтверждённые замечания исправлены.
- В самой игре ИИ не запускал ничего — всё проверено только офлайн; визуальные проверки — рендерами PIL.

## 8. Незавершённое, известные ошибки, заблокированное
- Не проверено в игре: интро (положение транспортника/контейнера), свечение замка (точное попадание в индикатор — подстройка `hla_lock_lamp_*`), камеры по VJ-зомби, боты в отрядах, предохранитель TFA.
- Модель `combine_train02b` и HL:A-замок не портированы: нужны `hl2_misc_001.vpk` / `pak01_319.vpk`; нет `studiomdl` для компиляции MDL.
- Оригинал HL:A-иконки Альянса в `pak01_424.vpk` — не прислан.
- `combine_alphabet.ttf` (глифы «COMBINE NETWORK STABLE») — у пользователя.
- Клиентские `util.IsValidModel` в `sh_items.lua`, `cl_editor.lua`, `hla_npc/cl_init.lua` могут давать ложное «нет» до предзагрузки модели (в интро и десантнике уже заменено на `file.Exists`).
- `sv_chat.lua` не проходит проверку синтаксиса в Lua 5.4 (присваивание переменной цикла) — в LuaJIT GMod это нормально.
