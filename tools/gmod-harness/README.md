# Тестовый стенд N-work

Дымовые тесты фреймворка без Garry's Mod: LuaJIT (через Python-пакет `lupa`)
с заглушками GMod API и настоящей SQLite в памяти.

```
pip install lupa
python3 run.py <корень-репозитория> server test_server.lua
python3 run.py <корень-репозитория> client test_client.lua
```

* `server` — загрузка серверной части, создание персонажей по сети, чат-классы
  и дистанции, рация, команды и права, инвентарь и стопки, предметы, нужды,
  сохранение/выгрузка персонажа.
* `client` — загрузка клиента, приём чата и уведомлений, все HUD-хуки, экраны
  меню, каждая вкладка меню персонажа, радиальное меню, чат-бокс.

Стенд ловит ошибки Lua и логики, но не показывает картинку — внешний вид
проверяется в игре.
